## Building with StockSmith UI

StockSmith is a desktop (Tauri) stock-control app: light theme only, dense 12.5–13px UI, system font stack (no web fonts — nothing to load). Components are plain React functions on `window.StockSmithUI`; **no provider, theme wrapper or context is needed** — mount them directly.

### Styling idiom: Tailwind v4 utility classes — a *closed* vocabulary
Style your own layout glue with Tailwind classes, **but only classes that already exist in `styles.css`** (it `@import`s `_ds_bundle.css`, the compiled sheet). The sheet was generated by scanning the app, so any class not listed there — a colour shade, a size, an arbitrary value — has **no CSS and renders unstyled**. Read `styles.css` before inventing a class. Families that exist:

| Concern | Use these (real names from the sheet) |
|---|---|
| Page/app shell | `flex h-screen overflow-hidden bg-slate-50 text-slate-900`; sidebar `w-[198px] flex-none flex-col border-r border-slate-200 bg-white p-2.5` |
| Surfaces | `rounded-lg bg-white shadow-sm` (cards, tables); `rounded-md bg-white p-3 shadow-sm` (settings rows) |
| Text | sizes `text-xs text-sm text-base text-lg text-xl text-[10.5px] text-[11px] text-[12.5px] text-[13px]`; colours `text-slate-400/500/600/700/900`, `text-red-600/700`, `text-amber-700/800`, `text-green-600/800`, `text-emerald-800`, `text-sky-800`, `text-blue-700`; weights `font-medium font-semibold`; `tabular-nums` for numbers, `font-mono` for SKUs |
| Primary button | `rounded-md bg-slate-900 px-3 py-1.5 text-sm text-white disabled:cursor-not-allowed disabled:opacity-50` |
| Secondary button | `rounded-md border border-slate-300 px-3 py-1.5 text-sm` |
| Destructive button | `rounded-md bg-red-600 px-4 py-2 text-sm text-white` |
| Inputs / selects | `rounded border border-slate-300 px-2 py-1 text-sm` (+ `w-28` for numbers) |
| Tables | `<table className="w-full border-collapse overflow-hidden rounded-lg bg-white text-left text-[12.5px] shadow-sm">`, header row `border-b border-slate-200 bg-slate-50/60`, cells `p-2`, numeric cells `text-right tabular-nums` |
| Nav row | `flex w-full items-center gap-2 rounded-md px-[9px] py-[7px] text-[13px] font-medium hover:bg-slate-100`; active adds `bg-slate-100 text-slate-900`, inactive `text-slate-600` |
| Spacing | `gap-1 gap-1.5 gap-2 gap-3 gap-4 gap-6`, `p-2 p-3 p-4`, `px-3 py-2`, `mt-1 mt-2 mb-2 ml-2` |
| Layout | `flex flex-col flex-1 items-center justify-between justify-end`, `grid grid-cols-2 grid-cols-3 gap-2`, `min-w-0 shrink-0 truncate` |

Colour meaning is fixed by the app: **slate** = neutral chrome, **blue-600** = the active tab underline, **red** = destructive/critical, **amber** = warning/ordered/due, **green/emerald** = received/OK, **sky** = part-received.

### Component rules
- `Badge` takes a required `className` carrying the colour pair — use only these pairs: `bg-amber-100 text-amber-800` (Ordered/Warning), `bg-sky-100 text-sky-800` (Part received), `bg-green-100 text-green-800` (Received), `bg-red-100 text-red-800` (Critical), `bg-emerald-100 text-emerald-800` (OK), `bg-slate-100 text-slate-600` (neutral/inactive).
- `FilterTabs` sits above a list table (tabs with counts); `Tabs` switches panes inside a `DetailPanel`. Don't swap them.
- `Th` + `GroupHeaderRow` are the *only* shared table parts — write the `<table>`, `<tbody>` and `<td>`s yourself with the table classes above.
- `Modal`, `ConfirmDialog`, `UnsavedChangesDialog` and `DetailPanel` are `position: fixed` full-viewport overlays: render one at a time at the top level of the screen, never inside a card. `ConfirmDialog`/`UnsavedChangesDialog` take `open`; `Modal`/`DetailPanel` render whenever mounted.
- `SaveButton` is disabled until `isDirty` — that *is* the "everything saved" signal; pair every form with one rather than an always-on button.
- Icons (`OrdersIcon` etc.) are 16px `currentColor` glyphs — colour them via the parent's `text-*` class.

### Where the truth lives
Read `styles.css` (and the `_ds_bundle.css` it imports) for the exact class list, and `components/<group>/<Name>/<Name>.prompt.md` for each component's props and verified example JSX.
